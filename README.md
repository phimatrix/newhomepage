# SeedLaunch Homepage

Homepage for [SeedLaunch](https://seedlaunch.co) — clarity, positioning and GTM narrative for seed-stage SaaS and AI founders. Built with plain HTML and hosted on GitHub Pages.

## Files
- `index.html` — the homepage
- `assets/` — images and static files

## Run
Open `index.html` in a browser, or serve the folder with any static server.
